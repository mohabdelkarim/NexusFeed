# NexusFeed

Autonomous Telegram news curator for AI and software engineering news.

## What It Does

### Breaking News Bot (`main.py` / `news_bot.py`)
- Fetches 15 curated RSS feeds in parallel with `ThreadPoolExecutor(max_workers=15)`.
- Keeps only articles published in the last 24 hours.
- Sends at most 25 candidates to Groq in one JSON-mode request per run.
- Uses a fixed Groq JSON response schema, including `telegram_message`, to avoid a second AI call.
- Deduplicates by canonical URL hash and by cross-source title similarity over 80% word-overlap.
- Posts at most 1 article per run and 3 per UTC day to Telegram.
- Persists `daily_state.json` and `posted_articles.json` back to the repository through GitHub Actions.

### Daily Digest Bot (`daily_digest.py`)
- Runs once daily at 21:00 Greece time (18:00 UTC).
- Fetches all 15 feeds and filters to the last 24 hours.
- Sends up to 30 candidates to Groq for a top-5 ranking.
- Uses local `digest_history.json` for deduplication (exact URL hash + 80% title overlap over 3 days).
- Sends one formatted Telegram message with the top 5 stories.
- Commits `digest_history.json` back to the repository after each run.

## Required Secrets

Configure these repository secrets before enabling the workflows:

- `GROQ_API_KEY`
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHANNEL_ID`

The bots validate all required runtime secrets at startup and fail fast if one is missing.

## Local Run

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python main.py
```

For the daily digest, run:

```bash
python daily_digest.py
```

## Workflows

### Breaking News Bot
The scheduler lives in `.github/workflows/news-bot.yml` and uses the required concurrency guard, `GITHUB_TOKEN` repository writes, and `[skip ci]` on state commits to prevent commit loops:

```yaml
concurrency:
  group: news-bot
  cancel-in-progress: false
```

### Daily Digest Bot
The scheduler lives in `.github/workflows/daily-digest.yml` and runs once daily at 21:00 Greece time (18:00 UTC):

```yaml
on:
  schedule:
    - cron: "0 18 * * *"
  workflow_dispatch:

concurrency:
  group: daily-digest
  cancel-in-progress: false
```

## Groq Contract

The bot sends an exact system prompt plus an exact JSON response contract to Groq. The response must include:

- `articles` (breaking news) or `digest` (digest)
- `best_index` / `best_score` / `recommendation` (breaking news)
- `rank`, `full_title`, `one_line_summary`, `source_name`, `source_tier`, `score`, `article_url` (digest)
- `telegram_message` (breaking news only)

The Telegram message is generated by Groq in one call and sent as Markdown.

## State Files

### Breaking News Bot
- `posted_articles.json`: stores hashes, recent titles (24h), and hash records (7d retention)
- `daily_state.json`: stores daily counters and `pending_best` for deferred posts

### Daily Digest Bot
- `digest_history.json`: stores URL hashes and recent titles (7d retention) for deduplication across runs
